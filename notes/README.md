## 命名与组织约定

- 文件名：`p<序号>_<阶段主题>.md`，序号按时间递增、不复用（`p1` → `p2` → `p3`…）。
- 一篇记录一个阶段，写清四件事：
  1. **目标**：这一步要达成什么；
  2. **步骤**：实际做了什么，附关键命令/配置（可直接复制）；
  3. **问题**：遇到的报错与解决方式；
  4. **结论/下一步**：当前状态与待办。
- 可复用的操作写成速查表（参考 `p1`），方便新项目照抄。
- 记录只写真实执行过、验证过的内容；未验证的设想单独标注为「计划」。
