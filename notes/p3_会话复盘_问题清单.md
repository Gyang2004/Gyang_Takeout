## 4. 登录功能审计

### 4.1 已具备（代码层闭环）

- [x] 后端 `POST /admin/employee/login`，返回 `Result<EmployeeLoginVO>`（`EmployeeController.java:42-61`）。
- [x] 密码 MD5 后与库比对，显式 UTF-8（`EmployeeServiceImpl.java:54-60`）。
- [x] 账号不存在、密码错误、账号被禁用三种异常（`EmployeeServiceImpl.java:49-65`）。
- [x] 登录成功生成 JWT，payload 放 `empId`（`EmployeeController.java:48-53`）。
- [x] TTL 1 天、请求头名 `token`（`application.yml:42-44`）。
- [x] 拦截器校验 `/admin/**`，登录接口放行（`WebMvcConfiguration.java:43-45`、`JwtTokenAdminInterceptor.java:42-56`）。
- [x] 前端登录页：必填、长度校验、loading、错误提示（`views/login/index.vue:19-25`）。
- [x] 登录态持久化到 localStorage（`utils/auth.js:1`、`stores/user.js`）。
- [x] 路由守卫：未登录跳登录、已登录不进登录页（`router/index.js:12-24`）。
- [x] 请求拦截器带 token；响应 401 清 token 跳登录（`api/request.js:14-37`）。
- [x] 退出清理本地登录态（`stores/user.js:43-63`）。
- [x] Vite 代理 `/api` → `/admin`（`vite.config.js:15-22`）。

### 4.2 不完善

- [ ] **端到端验证未完成**：后端是否已重启、库名/密码是否正确、curl 是否能拿到 token，都还没确认。
- [ ] 密码和 token 仍会进日志（P1）。
- [ ] 没有自动化测试（P1）。
- [ ] 没有失败次数限制（P2）。
- [ ] 退出不使 token 立即失效（P2）。
- [ ] MD5 不是密码存储的最佳实践（P2）。
- [ ] 后端没有 `logging.file`，出问题只能看控制台（P2）。
- [ ] 服务端没有参数校验（P3）。

### 4.3 结论

**代码层面基本闭环，可以登录、可以拦截、前端可跳转；但不能算「完善」。**
准确说法是：**登录功能已实现，待端到端验收**。当前第一优先级是确认「后端已重启 + 数据库是同一个库 + admin 密码是 MD5」这三件事。

## 5. 下次启动 / 停止

### 启动

```text
1. MySQL 服务启动
2. 后端：IDEA Run SkyApplication（或 mvn -pl sky-server -am spring-boot:run）
3. 前端：cd frontend && npm run dev（首次或依赖变动先 npm install）
4. 浏览器打开 http://localhost:5173
```

开发阶段不需要 Nginx；Nginx 只在验证 `npm run build` 产物时用。

### 停止（PowerShell）

```powershell
# 前端 5173
Get-NetTCPConnection -LocalPort 5173 -State Listen -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_ -Force }

# 后端 8080
Get-NetTCPConnection -LocalPort 8080 -State Listen -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_ -Force }
```

Nginx 如果开着：在 `nginx/` 目录执行 `.\nginx.exe -s quit`。
MySQL 可以不停；要停就在 `services.msc` 停 `MySQL80`。
