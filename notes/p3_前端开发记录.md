# 前端开发记录（模块 1：工程初始化 + 登录闭环）

> 关联：[前端重构方案](../docs/p3/前端重构方案.md)、[登录态复盘](p3_登录态复盘.md)。
> 约定：每完成一个模块，记录范围、关键决策、验收结果，验收通过后再进入下一个模块。

## 1. 本模块范围

对应方案 §5 的阶段 0 + 阶段 1：

- `frontend/` 工程：Vite 5、Vue 3、Vue Router 4、Pinia 2、Axios、Element Plus、Sass、ESLint + Prettier。
- 登录页：账号/密码校验、loading、错误提示、回车提交。
- 登录闭环：登录存 token → 跳转；路由守卫；刷新恢复；401 清理并跳登录；退出。
- 临时落地页：`views/dashboard/index.vue`（模块 2 会被正式布局替换）。
- 404 兜底页。

不在本模块：侧边栏/面包屑/菜单（模块 2）、员工 CRUD 等业务页面（等后端）。

## 3. 与方案不一致的地方

| 项 | 方案 | 实际 | 原因 |
|---|---|---|---|
| Element Plus 引入方式 | `unplugin-auto-import` + `unplugin-vue-components` 按需引入 | 全量 `app.use(ElementPlus)` + SCSS 主题入口 | 方案 §4.7 需要编译 `theme-chalk/src/index.scss` 定制主题；全量引入与该主题入口一致、配置更少。管理端体积可接受。若后续要做包体优化，再切按需引入（需同时调整 SCSS 注入方式），届时单独验收 |
| 环境变量文件 | `.env.development` / `.env.production` | 同上，并修改根 `.gitignore` 放行这两个无密钥文件 | 根 `.gitignore` 原本忽略所有 `.env.*`，不放行会导致换机器构建缺少配置 |

### 4.2 启动与登录

```bash
# 终端 1：后端（需 application-dev.yml 与本地 MySQL 就绪）
cd backend
mvn -pl sky-server -am spring-boot:run

# 终端 2：前端
cd frontend
npm run dev        # http://localhost:5173
```

| 场景 | 期望 |
|---|---|
| 未登录访问 `/dashboard` | 跳 `/login?redirect=/dashboard` |
| 错误密码 | 表单下方/顶部出现后端错误提示，停留在登录页 |
| 正确账号密码 | 提示「登录成功」并进入 `/dashboard`，显示员工姓名 |
| 刷新 `/dashboard` | 登录态保持，不跳登录 |
| 已登录访问 `/login` | 自动回 `/` |
| 点击退出 | 回到 `/login`，localStorage 中 `token` 被清除 |
| 手工把 token 改成非法值后请求 | 后端 401 → 清理 token → 跳 `/login` |
| 访问不存在路由 | 显示 404 页，可返回首页 |
