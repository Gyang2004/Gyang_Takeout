## 1. 本模块范围

对应方案 §5 的阶段 0 + 阶段 1：

- `frontend/` 工程：Vite 5、Vue 3、Vue Router 4、Pinia 2、Axios、Element Plus、Sass、ESLint + Prettier。
- 登录页：账号/密码校验、loading、错误提示、回车提交。
- 登录闭环：登录存 token → 跳转；路由守卫；刷新恢复；401 清理并跳登录；退出。
- 临时落地页：`views/dashboard/index.vue`（模块 2 会被正式布局替换）。
- 404 兜底页。

不在本模块：侧边栏/面包屑/菜单（模块 2）、员工 CRUD 等业务页面（等后端）。

## 3. 与方案不一致的地方

| 项 | 方案 | 实际 | 原因 |
|---|---|---|---|
| Element Plus 引入方式 | `unplugin-auto-import` + `unplugin-vue-components` 按需引入 | 全量 `app.use(ElementPlus)` + SCSS 主题入口 | 方案 §4.7 需要编译 `theme-chalk/src/index.scss` 定制主题；全量引入与该主题入口一致、配置更少。管理端体积可接受。若后续要做包体优化，再切按需引入（需同时调整 SCSS 注入方式），届时单独验收 |

### 4.3 登录闭环（通过）

后端以空口令覆盖启动（`-Dspring-boot.run.arguments="--sky.datasource.password="`），用本机 Edge 无头浏览器 + CDP 跑完整交互：

| 场景 | 实际结果 |
|---|---|
| 登录页渲染 | 通过 |
| 错误密码 | 提示「密码错误」，停留 `/login` |
| 正确账号 `admin/123456` | 跳 `/dashboard`，显示「欢迎回来，管理员。」，token 长度 103，`name=管理员` |
| 刷新 `/dashboard` | 仍在 `/dashboard`，token 保留 |
| 已登录访问 `/login` | 自动回 `/dashboard` |
| 退出 | 回 `/login`，`localStorage.token = null` |
| 非法 token 调接口 | 后端 401 → 清理 token → 跳 `/login` |

接口契约（经 Vite 代理）：登录成功 `{code:1,...}`；错误密码 `{code:0,msg:"密码错误"}`；有效 token 退出 `code:1`；非法 token 退出 HTTP 401。

### 4.4 启动配置问题（待处理）

`application-dev.yml:6-8` 当前为：

```yaml
database: sky_take_out_new
username: root
password: root
```

本机实际：`sky_take_out_new` 已导入 16 张表（与配置一致）；MySQL `root` 是**空口令**，所以 `password: root` 会 `Access denied`。本次验收用命令行 `--sky.datasource.password=` 覆盖，**没有修改配置文件**。

建议二选一：

- 把 `password: root` 改为 `password:`（空值），或改成真实口令；
- 后续把口令改为环境变量注入（方案 §6.4）。

另：本地 `employee` 表中只有 `admin` 被刷成明文 `123456`，`tom/marry/kitty` 等仍是 MD5；后端当前明文比对（`EmployeeServiceImpl.java:53-56` TODO），这些账号登录会报密码错误。是否统一加密比对由后端排期决定。

> 后端启动命令修正：`mvn -pl sky-server -am spring-boot:run` 会在父 POM 上执行并报 “Unable to find a suitable main class”；应先 `mvn -DskipTests install`，再 `mvn -f sky-server/pom.xml spring-boot:run`。
