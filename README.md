# Gyang_Takeout

一个从零开始开发的外卖平台项目，主要用于学习与实践。

## 项目简介

本项目是一个外卖平台（Takeout）的学习型项目，从零开始搭建，记录完整的开发过程。项目旨在通过这个实战案例，学习和掌握全栈开发的相关技术与工程实践。

## 功能特性

> 功能规划中，将随着开发进度持续更新与完善。

- 用户注册与登录
- 商家与菜品浏览
- 购物车与下单
- 订单管理
- （更多功能开发中……）

## 学习记录

开发过程中的阶段心得与总结统一存放在 [`notes/`](./notes/) 目录下，按阶段以 Markdown 文档的形式维护，方便回顾与沉淀。
